# Iconos PWA

Coloca aquí los íconos del logo Admiral en estos tamaños:

- `icon-192.png` (192×192 px, mínimo para PWA)
- `icon-512.png` (512×512 px, para splash screen)

Recomendación: generar con [favicon.io](https://favicon.io/) o
[realfavicongenerator.net](https://realfavicongenerator.net/) usando el logo navy + gold.

Mientras tanto, Next.js sirve un favicon por defecto.
